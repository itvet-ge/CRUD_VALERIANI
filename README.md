# introduce Spring Boot Web
## Company CRUD

__დაწერეთ კომპანიის CRUD აპლიაკაცია__

კომპანიის ველები:
* id (იდენტიფიკატორი)
* sphere (ბიზნეს სფერო/სექტორი რასაც ის მოემსახურება)
* name (სახელწოდება)
* mail (საკონტაქტო მეილი)
* capital (საწყისი კაპიტალი)
* releaseDate ( თარიღი როდესაც კომპანია დაარსდა )

დაამატეთ endpointები
* id-იდ წამოღება
* ყველას წამოღება (paging-ით)
* ახლის შექმნა
* რედაქტირება
* წაშლა

მინიმალური მოთხოვნები
* თითოეულ endpointს დააწერეთ swagger-ის განმარტება რას აკეთებს ის 
* კომპანიის თითოეულ ველს დააწერეთ swagger-ის განმარტება რას მნიშვნელობას ინახავს ის  
* ე.წ. ბაზად გამოიყენეთ csv ფაილი. ანუ იქ შეინახეთ ჩანაწერები.
* კომპანიის ველებს დაადეთ ვალიდატორები: მაგ: მეილი უნდა იყოს სწორი ფორმატის, კომპანიის დაარსების თარიღი არ იყოს მომავალი და ა.შ.
* ბიზნეს სფეროს მიხედვით განსაზღვრეთ მინიმალური კაპიტალის ოდენობა. დაადეთ ვალიდატორი;
* დააბრუნეთ შესაბამისი http სტატუსები (როგორც შეცდომის დროს ისევე წარმატებით შესრულების დროს).
